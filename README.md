# TWTECH Consultoria

Site institucional estático da TWTECH Consultoria, feito com HTML e CSS puro.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie o conteúdo desta pasta para a branch `main`.
2. Em **Settings > Pages**, selecione **GitHub Actions** como fonte de publicação.
3. O workflow em `.github/workflows/pages.yml` fará o deploy automaticamente a cada push na `main`.

O site não precisa de Node.js, build ou variáveis de ambiente.
